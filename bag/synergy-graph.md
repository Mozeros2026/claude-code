# The Bag — cross-entity synergy graph

> "The bag" = the cross-client/portfolio layer from Build Spec v1. It's the data
> that powers **C5 Cross-Bag Synergy Detector**: asymmetric opportunities *across*
> seemingly unrelated entities (cf. CS2 — bring partners, become the local). The
> [registry](../registry/registry.md) is the node index; this graph is the
> *edges* between nodes. **The engine that proposes + maintains these edges is C6**
> ([`../frameworks/mo-commas/c6-cross-bag-synergy.md`](../frameworks/mo-commas/c6-cross-bag-synergy.md),
> `/momega-synergy`).

**Landmine:** synergy quality depends on bag completeness. A sparse/stale graph
yields weak hypotheses — keep it current (see [`../frameworks/falsifiers.md`](../frameworks/falsifiers.md)).

**Edge convention (C6).** Every edge cites the **two Brain sections it bridges**
(one per node) in the Hypothesis cell — an edge without a two-sided cite is a
`[[ HITL ]]` hypothesis, not a stated edge. `Type` ∈ {shared-buyer · warm-intro ·
complementary · portfolio · shared-risk}. Superseded edges are kept with
`retired` status, never deleted. New fields → add the column here and note it in
this block (the convention is self-tuning; never silently drop a node).
