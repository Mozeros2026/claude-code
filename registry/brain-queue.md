## How readiness is detected (and its honest limits)
- **Local materials:** non-README files under `entities/<type>/<id>/materials/`.
- **Vault materials:** the node id appears in `registry/vault-manifest.md`.
- **Freshness:** read from the materials `README.md` **Status column** (✅/ingested),
  NOT file mtimes — this repo is cloned fresh each session, so mtimes are unreliable.
